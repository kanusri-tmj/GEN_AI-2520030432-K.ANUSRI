# Week 6 – LLM Baseline Evaluation

## About the Experiment

In this experiment, I learned how to evaluate the responses generated by a Large Language Model (LLM).

I used Ollama with the Llama 3.2 model to answer a set of predefined questions. The generated answers were compared with expected answers using keyword matching. The program calculated scores for each question and saved the results in a CSV file.

## What I Did

- Created a set of 30 predefined questions.
- Prepared expected answers and keywords for each question.
- Connected Python with Ollama.
- Used the Llama 3.2 model to generate answers.
- Compared the generated answers with the expected keywords.
- Calculated the keyword matching percentage.
- Assigned PASS or REVIEW status based on the score.
- Saved the evaluation results in a CSV file.
- Generated a final evaluation summary.

## How to Run

1. Open the project folder in VS Code.
2. Install the required library:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Make sure Ollama is installed and running.
4. Make sure the Llama 3.2 model is available. If not, run:

   ```bash
   ollama pull llama3.2
   ```

5. Run the Python program:

   ```bash
   python main.py
   ```

6. Wait for the model to answer all 30 questions.
7. Check the evaluation results in the terminal and the generated CSV file.

## Evaluation Method

The program uses keyword-based scoring to check the generated answers.

- **PASS:** Score is 60% or above.
- **REVIEW:** Score is below 60%.
- **ERROR:** The program could not successfully get a response.

The average keyword coverage is also calculated to understand the overall performance of the model.

## Output

The program displays:

- Questions asked.
- LLM-generated answers.
- Expected answers.
- Matched and missing keywords.
- Individual scores.
- PASS, REVIEW, or ERROR status.
- Overall average keyword coverage.

All results are saved in `baseline_results.csv` for future reference.
